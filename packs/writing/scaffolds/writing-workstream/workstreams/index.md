# Workstreams

Each **workstream** is one deliverable tracked end-to-end. The shared research
corpus — `/sources/`, `/analyses/`, `/notes/`, `/tasks/` — feeds every
workstream; the *writing* (outline → draft → review → published) lives inside
the workstream so a single folder shows the whole thing.

Every workstream still runs the required steps from CLAUDE.md. Research is done
once, in the shared corpus, and drawn on by all workstreams; only the writing
stages are per-workstream.

## Adding a workstream

Create `workstreams/<name>/` with `outlines/`, `drafts/`, `reviews/`,
`published/`, an `index.md` hub, and any planning docs. Add a row above. The
research it needs is gathered in the shared corpus, not duplicated here.
