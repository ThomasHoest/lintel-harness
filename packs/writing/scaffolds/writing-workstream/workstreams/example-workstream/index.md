# Example workstream — hub

*(Rename this folder to your deliverable and rewrite this hub. It exists so the
stage folders below have somewhere to hang and so the shape is visible before
the first real workstream starts.)*

One deliverable, tracked end to end. The research it draws on lives in the
shared corpus (`/analyses/`, `/sources/`, `/notes/`); only the writing stages
live here.

## Stages

| Stage | Folder | Who writes it |
|---|---|---|
| Outlines | [outlines/](outlines/index.md) | `outliner` — 2–3 genuinely different structures; the user picks |
| Drafts | [drafts/](drafts/index.md) | `writer` — versioned, never overwritten |
| Reviews | [reviews/](reviews/index.md) | `critic` — adversarial, loop capped at two |
| Published | [published/](published/index.md) | the user, after a final read. Never an agent |

## Planning docs
