# Writing guide

Reusable writing guidance: how Thomas writes, and the screen that keeps drafts sounding like a person. Meant to **evolve over time** and to be **copied into other projects**.

## What's here

- [tone-of-voice.md](tone-of-voice.md) — the register: plain, first-person, unhyped. How Thomas actually writes.
- [ai-tells.md](ai-tells.md) — the final screen that removes AI giveaways from any Thomas-facing draft before it ships (em-dashes are the #1 tell).
- [bilingual-publishing.md](bilingual-publishing.md) — how a finished post is recorded when it ships in two languages: one file per language, header + `---` + prose, translate and screen last.

*Growing:* add channel-specific docs as needed (`linkedin.md`, `cover-letters.md`, `outreach.md`).

## How to use

1. Draft with `tone-of-voice.md` in mind.
2. Run the `ai-tells.md` screen as a **final pass** on anything before it ships (and while drafting, so the tells don't go in to begin with).

## Portability

The core (tone + the AI-tells screen) is deliberately project-agnostic, so you can drop this folder into another repo. The one project-specific dependency is the **voice samples** (real examples of Thomas's writing) referenced in `tone-of-voice.md`; in a new project, point that section at wherever the samples live.
