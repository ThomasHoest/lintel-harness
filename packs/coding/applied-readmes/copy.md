# `copy/` — user-facing text

| File | What it is |
|---|---|
| `tone-of-voice.md` | The voice guide all user-facing copy is written against |

**`tone-of-voice.md` starts empty and must be filled in.** The
`copywriter` agent halts rather than guessing a voice, so until this
file has real content — audience, tone, length norms, a do/don't list, a
lexicon, and above all worked examples — no copy gets written.

Worked examples do the most work here. An agent matching your voice from
three real before-and-after samples will get closer than one working
from adjectives.

Copy decks produced against this guide live with their feature specs,
not here.
